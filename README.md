## 有什么

| 功能 | 说明 |
|---|---|
| 🏠 首页曲库 | 不带 `?song=` 打开网站，看到的是所有支持的歌一张张卡片摆开——YouTube 封面当预览图、句数、练习/KTV、时间轴校准状态，点哪张进哪首；上次学的那首会标「上次在学」。歌里右上角 🏠 随时能回这里 |
| 🎵 选歌 | 右上角切歌，曲库里每首歌各自记进度；换歌走 `?song=id`，链接可以直接分享到某一首 |
| 🎤 KTV 双行显示 | 左右两格固定位置：第 1/3/5… 句永远在左，第 2/4/6… 句永远在右。正在唱的那句**位置从不移动**，换的永远是另一边，提前铺好下下句，眼睛不用来回找 |
| 🎬 KTV 背景放 MV | 音源就是官方 MV，沉浸模式直接把这块画面撑满全屏当背景，歌词盖在上面，画面和歌天然同步。右上角 🎬 可以关掉换回纯色背景，选择记在浏览器里 |
| 🔇 画面可关 | 默认「只要声音」，把视频完全收起只留音轨；也可切「小窗 / 大窗」 |
| 🎵 跟着原曲走 | 内嵌 YouTube 原曲，播放时当前句自动高亮、自动滚动 |
| 🔊 真的能发音 | 点「整句」听整句，点**任意一个词**只听那个词。用浏览器内置语音合成，不需要联网 API |
| 🔁 单句循环 | 一句反复放，跟读练到会为止 |
| 🐢 变速 | 原曲 0.5×–1.25×；朗读语速 0.3×–1.2× 单独可调 |
| 📝 逐词卡片 | 每个词都有 泰文 / 罗马音 / 中文谐音 / 中文意思 |
| 🎙 跟读录音 | 录下自己读的，立刻回放跟原唱对比 |
| 🃏 单词表 | 每首歌的词自动摊成一张表（Safe Near Me 是 63 个），泰语 / 罗马音 / 谐音 / 意思 / 掌握程度，能排序筛选，也能复制出去 |
| 🎯 四选一测验 | 一次一张词卡，四个**意思相近容易混**的中文选项，选对升级选错降级，答完给出这个词在歌里的原句 |
| ⚔️ 双人对战 | 一道题出来**两个人同时抢**：开了摄像头就比手指（比几根 = 第几个选项），没开就按键盘（一个人 1234、一个人 7890）；先答对的当场 +1，抢错的这题出局。开局各拍一张照片，两张脸和比分整局挂在屏幕上 |
| 📊 掌握程度 | 每个词 0–5 级：连对 5 次到「已掌握」，错一次掉一级；越不熟的词测验时出现得越勤 |
| ✓ 掌握标记 | 学会的句子打勾，进度存在浏览器里 |
| ⏱ 时间轴校准 | 跟着歌一句按一次空格，放一遍歌就把歌词对准了；中途能存，下次接着标 |
| 👀 显示开关 | 罗马音 / 谐音 / 意思 / 词卡可以各自关掉，用来自测 |

快捷键：`空格` 播放暂停 · `←` `→` 上下一句 · `R` 单句循环 · `S` 朗读当前句
单词模式里：`1`–`4` 选答案 · `Enter` 下一个 · `Esc` 回单词表

## 单词模式：把这首歌的词背下来

右上角切到 **🃏 单词**。**每首歌一份自己的单词表和进度**，换歌自动跟着换；
没有时间轴的歌（`timeline: false`）也照样能用，背单词不依赖逐句同步。里面三块：

### 单词表

歌词里每个词的卡片自动去重摊成一张表 —— 歌词改了表跟着变，不会对不上。一行是一个词：

```
1  อาจจะ      也许        ●●●●●  已掌握  ✓3 ✗0     🎵 📖 ✓ ↺
   at cha
   啊扎
```

- **点卡片任意位置**听这个词的发音（跟练习模式里点词一样）
- **🎵** 放这个词所在的**原句**，唱完这一句自动停，不会一路放下去。
  没时间轴的歌（`timeline: false`）放不了原曲，这里改成朗读整句；
  YouTube 还没加载好的时候也一样退回朗读，不会点了没声音
- **📖** 回歌词里看这个词在哪句，那个词会闪一下
- **✓** 这词我本来就会，直接标满；**↺** 清掉重学
- 能按 **歌词顺序 / 最不熟的在前 / 出现最多的在前** 排，也能只看「还没掌握 / 答错过的 / 已掌握」
- 勾上**「遮住意思」**就是一张自测表：先自己想，点一下才揭开
- **📋 复制单词表** 复制成制表符分隔的一张表，贴进 Excel / Notion / Anki 都能直接用；想打印出来带着背就直接 Ctrl/⌘+P，测验和按钮不会被打进去

### 四选一测验（一个人）

点 **🎯 开始测验**，一轮 10 题。每题给一张词卡（泰语 + 罗马音，出题时自动读一遍），下面四个中文意思。

四个选项里那三个错的是**手写**的，专挑容易混的：

| 考的词 | 正确答案 | 三个干扰项 |
|---|---|---|
| ทำให้เธอเหงา | 让你孤单 | 让你难过委屈 / 让你等太久 / 让你害怕 |
| อย่าโกรธ | 别生气 | 别惩罚 / 别难过 / 别走 |
| ใกล้ | 靠近 | 远离 / 在里面 / 路过 |

选完立刻判对错，并且把这个词在歌里的**原句**亮出来，顺手记住它是怎么用的。
对错都**停在那儿等你点「下一题」**（焦点直接落在按钮上，敲回车就行）—— 答对了也不抢着往下翻，留出看原句的时间。
一轮结束给正确率，把这轮错的词单独列出来。

### 双人对战：一道题出来，两个人同时抢

点 **⚔️ 双人对战**，两个人并排坐一台电脑前，**一道题两个人同时抢** ——
谁先答对，当场 **+1**；抢错的人这道题就出局了，剩下的时间只剩另一个人能答。

```
①  填名字、选题数（5 / 10 / 15 / 20），想用手势就把摄像头开上
②  各拍一张开场照 —— 一张画面从中间切两半，左边那半是玩家 1，右边那半是玩家 2
③  「准备」一拍 → 题目亮出来 → 两个人同时抢
      比 ✌️ 两根手指  = 第 2 个选项      阿明 按 1 2 3 4
      比 🖖 四根手指  = 第 4 个选项      小美 按 7 8 9 0
④  抢对了当场加分，屏幕上直接公布答案
⑤  两个人**一起比 ✊**（或者按两下空格）进下一题
⑥  打完揭晓：4 : 2，外加逐题对照
```

**记分牌整局挂在最上面**：两张开场照、两个名字、两个分数，从第一题挂到最后一题。
谁领先、谁刚抢错这题出局了、对面这会儿正比着几根手指，抬头就看得见 —— 这才有比赛的样子。

**手势是怎么认的：**

- 画面按自拍的习惯**左右镜像**显示，所以「你坐屏幕左边」和「你在画面里出现在左边」是一回事，
  不用先在脑子里翻一道。手伸在哪半边，这只手就算谁的，两个人各管各的半边，抢起来互不打架。
- 只数**食指、中指、无名指、小指**这四根，**拇指一概不算** —— 比「1」有人竖食指有人竖拇指，
  比「3」有人是食中无名、有人是拇食中，只数四根反而人人比出来都一样，
  而且 1–4 刚好对上四个选项。四根全蜷起来就是 ✊。
- 手势要**稳住三帧**才算数，手挥过去、比划到一半路过某个数，都不会误抢。
- 用的是 Google MediaPipe 的 HandLandmarker，第一次要从 CDN 下大约 8 MB，之后走浏览器缓存。

**键盘那套任何时候都在**（玩家 1 `1234`、玩家 2 `7890`）：
摄像头没开、模型没下下来、手没伸进画面、认岔了 —— 哪种情况都还能把这局打完，
手势坏了不至于卡住游戏。用鼠标或者触屏点选项也行，还是那套左右分工：
**点在选项左半边算玩家 1，右半边算玩家 2**。

**抢错为什么要出局：** 不然最优解就是把四个选项全按一遍。抢错了不光自己这题没份，
错的那个选项还会当场标出来，等于白送对面一个线索 —— 手快之前得先想清楚，这才是抢答。

**每题 20 秒**，都没抢对就没人得分，直接公布答案，局不会卡在那儿。
一题结束要**两个人一起**比拳头才翻页，一个人点不动 —— 得等另一个看完答案，没人会被拖着走。

**揭晓那一屏**给两边的分数、平均抢答速度、胜负，下面是逐题对照：每道题的正确答案、
两个人各自抢了什么（✓ / ✗，带用时）、哪几题谁也没抢对，以及这个词在歌里的原句。
打完可以「再来一轮」「重拍照片」，一场里的总比分会一直累计着。

> 摄像头画面**只在这台电脑的内存里转一圈**：不上传、不存盘，照片也一样 ——
> 退出对战摄像头当场关掉，照片跟着一起没。localStorage 里只存名字、题数、要不要开摄像头。

> 对战**不改动**单词表里的掌握程度。朋友来你电脑上玩一局，不会把你自己的学习进度搅乱；
> 出题倒是照样偏心不熟的词（级别越低越容易被抽中）。

快捷键：玩家 1 `1`–`4` / 玩家 2 `7`–`0` 抢答 · 两下 `空格` 进下一题 · `S` 再听一遍 · `Esc` 中断这局

### 掌握程度是怎么算的

每个词 0–5 级，**答对升一级，答错掉一级**：

| 级别 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 叫法 | 没学过 / 还生疏 | 刚见过 | 眼熟 | 会了 | 熟练 | 已掌握 |

一路答对最快 5 次到「已掌握」；错一次只掉一格，不会一夜回到解放前。出题时**级别越低的词抽中概率越大**，刚答错的还会再加权 —— 不熟的词自己会反复冒出来，不用手动挑。

进度按歌存在浏览器 localStorage 里（key 是 `tsl.vocab.<歌曲id>`），换设备不会跟着走。想推倒重来点「↺ 重置进度」。

## 第一次用要做的两件事

### 1. 装泰语语音（最关键）

发音靠的是**你设备里的泰语语音包**。右上角「发音」按钮旁边的圆点告诉你状态：

- 🟢 绿 = 已经能发音，直接用
- 🟡 黄 = 没检测到泰语语音，点进去按指引装一次

各平台装法（网页里也有）：

- **Mac** — 系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理声音 → 泰语 Kanya，下载
- **iPhone/iPad** — 设置 → 辅助功能 → 朗读内容 → 声音 → ไทย/Thai，下载
- **Windows** — 设置 → 时间和语言 → 语言和区域 → 添加「ไทย/Thai」（勾上语音）
- **Android** — 设置 → 文字转语音输出 → Google TTS → 安装语音数据 → ไทย

> 用**电脑版 Chrome** 打开通常自带在线泰语语音，可以省掉这一步。装完记得刷新页面。

### 2. 校准时间轴（只有带时间轴的歌需要）

`synced: false` 的歌（现在是《心命令我爱你》），仓库里的时间点是**估算的**，跟原曲对不准。点右上角 **⏱ 校准**：原曲从头播，每句唱到开头时按一下空格（标错了按退格退回上一句），全部标完点「保存时间轴」。结果按「歌 + 音源」存在浏览器里，下次打开自动生效，不用重标。

想让**所有访问的人**都用校准好的时间轴：校准面板点「导出给别人用」，把生成的数字贴回这首歌的文件里，并把文件顶部的 `synced` 改成 `true`，提交即可。导出的格式会跟着歌词文件的写法走：

- 每句自己写 `start` 的（[`songs/safe-near-me.js`](songs/safe-near-me.js)）→ 导出「句子 id + start」逐句列表；
- 时间集中放在文件顶部 `TIMES` 里的（[`songs/hua-jai-sang-hai-rak-thoe.js`](songs/hua-jai-sang-hai-rak-thoe.js)，因为副歌复用同一份歌词）→ 导出整块 `TIMES`，覆盖粘贴即可。这种文件要在歌曲数据里写 `timesStyle: 'grouped'`。

## 加新歌

1. 复制 `songs/` 里现成的一份改，文件名随意，放同一个目录；
2. 在 `index.html` 底部加一行 `<script src="songs/你的文件.js"></script>`；
3. 刷新，它就出现在「🎵 选歌」列表里了 —— 列表顺序 = `<script>` 的引入顺序，第一首是默认打开的那首。

只想练歌词、不想标时间轴，就写 `timeline: false`，其他字段照填，`start` 可以整个省掉。

单词表和测验都是从下面的 `words` 自动生成的，不用另外维护一份词表 —— 每首歌一份自己的进度。
测验的干扰项在 [`js/distractors.js`](js/distractors.js) 里按**泰文词**写，所以两首歌里都出现的词
（เธอ、ฉัน、หัวใจ…）自动共用同一套干扰项；**不写也能跑**，会从同类词堆和这首歌里别的词凑三个出来，
只是没手写的那么刁钻。数据结构：

```js
window.SONGS['歌曲id'] = {
  id, title, titleTh, titleCn, artist, album,
  youtubeId: 'YouTube 视频 ID',
  timeline: false,             // false = 只做练习模式，不做逐句同步（省掉下面的 start）
  synced: false,               // 有时间轴时：是否已用真实音频校准过（false 会提示去校准）
  timesStyle: 'grouped',       // 可选：时间集中写在 TIMES 里的歌写它，导出会按 TIMES 的格式给
  sections: [{
    name: '主歌 A', nameEn: 'Verse 1',
    lines: [{
      id: 'v1-1',              // 全曲唯一，「已掌握」的勾按它存
      lang: 'th',              // 'th' 或 'en'，决定用哪种语音朗读
      start: 15.0,             // 该句在原曲中的开始秒数（timeline: false 时不用写）
      th: '泰文整句', ro: '罗马音', cnRo: '整句中文谐音', cn: '中文意思',
      words: [
        { th:'词', ro:'罗马音', cn:'中文谐音', mean:'意思' },
      ],
    }],
  }],
};
```

副歌、预副歌唱好几遍的，可以像 `songs/hua-jai-sang-hai-rak-thoe.js` 那样，
把一段写成变量复用，只换 id 前缀，不用把同样的逐词卡片抄好几遍。
这种歌的 `start` 没法写在句子里（同一份歌词唱好几遍、时间各不一样），
就把时间按段落前缀集中放在文件顶部的 `TIMES` 里，再写上 `timesStyle: 'grouped'`。

## 说明

- 逐词释义和谐音来自使用者自己整理的学习卡片
- 原曲由 YouTube 官方播放器播放，本仓库**不含任何音频文件**
- 跟读录音只留在当前页面内存里，刷新即消失，不上传任何地方
- 歌词为第三方版权内容，仅供个人学习使用；公开传播前请自行确认授权情况
